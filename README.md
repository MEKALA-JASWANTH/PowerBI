# PowerBI Data Visualization Project

## Overview
This repository contains Power BI data visualization dashboards and analysis files focused on shipment tracking and profit calculation.

## Contents

### Visualizations
- **Shipment Count Dashboard** - Analysis of shipment volumes and tracking metrics
- **Profit Calculation Dashboard** - Financial analysis and profit tracking visualizations

### Folder Structure
- `folder-1/` - Additional project resources and supporting files

## Project Description
This project demonstrates data analytics capabilities using Microsoft Power BI to:
- Track and analyze shipment data
- Calculate and visualize profit metrics
- Create interactive dashboards for business intelligence

## Technologies Used
- Microsoft Power BI Desktop
- Data visualization and business intelligence tools

## How to Use
1. Clone this repository
2. Open the .pbix files (if available) in Power BI Desktop
3. Review the dashboard screenshots to understand the analytics approach
4. Connect to your own data sources to replicate the analysis
